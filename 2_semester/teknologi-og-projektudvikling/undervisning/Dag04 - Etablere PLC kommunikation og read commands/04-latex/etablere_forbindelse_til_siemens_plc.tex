\section{Introduktion}
% ==============================================================================

Siemens S7-PLC'er er et af de mest udbredte PLC-systemer inden for industriel automation.
For at kommunikere med dem fra Python bruger vi biblioteket \textbf{python-snap7},
som er en Python-wrapper til det åbne \texttt{snap7}-bibliotek skrevet i C++.

\begin{tcolorbox}[infobox, title={\faInfoCircle\quad Hvad er snap7?}]
\textbf{snap7} er et gratis, open-source bibliotek der implementerer Siemens S7
kommunikationsprotokollen (S7comm). Det understøtter S7-200, S7-300, S7-400,
S7-1200 og S7-1500 serien.
\end{tcolorbox}

\subsection{Installation}

Installer \texttt{python-snap7} via pip:

\begin{tcolorbox}[pythonbox, title={\faTerminal\quad Terminal — installation}]
\begin{minted}[style=native]{python}
pip install python-snap7
\end{minted}
\end{tcolorbox}

\begin{tcolorbox}[warnbox, title={\faExclamationTriangle\quad Vigtigt: PLC-opsætning i TIA Portal}]
Før Python kan tale med PLC'en skal følgende aktiveres i \textbf{TIA Portal}:
\begin{itemize}[itemsep=2pt]
  \item \textit{PUT/GET communication} skal være tilladt under \textit{Protection}
  \item \textit{Optimized block access} skal være \textbf{slået fra} i Data Block egenskaber
  \item IP-adressen på PLC'en skal kendes
\end{itemize}
\end{tcolorbox}

\section{Opret forbindelse til PLC}
% ==============================================================================

Den grundlæggende forbindelsesprocedure kræver PLC'ens \textbf{IP-adresse},
\textbf{rack}-nummer og \textbf{slot}-nummer.
For S7-1200/1500 er rack typisk \texttt{0} og slot \texttt{1}.
Nogle opsætninger kræver en specifik port (standard er \texttt{102}, men
kan ændres til f.eks. \texttt{1102}).

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 1 — Opret og afslut forbindelse}]
\begin{minted}{python}
import snap7

# ====== PLC opsætning ==========
plc_ip = "192.168.154.1"
rack   = 0
slot   = 1
port   = 1102

# ====== PLC forbindelse =========
client = snap7.client.Client()
client.connect(plc_ip, rack, slot, port)
print("Forbundet til PLC:", client.get_cpu_info())

# ====== Disconnect og destroy ===
client.disconnect()
client.destroy()
\end{minted}
\end{tcolorbox}

\begin{tcolorbox}[tipbox, title={\faLightbulb\quad God praksis}]
Kald \textbf{altid} \texttt{client.disconnect()} og \texttt{client.destroy()} til sidst.
Ellers kan PLC'en komme til at bruge resurser på en hængende forbindelse.
\end{tcolorbox}

\section{Læse data fra PLC (db\_read)}
% ==============================================================================

Data i en Siemens PLC er organiseret i \textbf{Data Blocks (DB)}.
Hver variabel har en byte-offset og en størrelse.
Nedenstående eksempel læser tre datatyper fra \texttt{DB1}:

\begin{center}
\begin{tabular}{lcccp{5cm}}
\toprule
\textbf{Variabel} & \textbf{Offset} & \textbf{Størrelse} & \textbf{Type} & \textbf{TIA Portal navn} \\
\midrule
Bool  & 0 & 1 byte & \texttt{DBX0.0} & DB1.DBX0.0 \\
Int   & 2 & 2 bytes & \texttt{DBW2} & DB1.DBW2 \\
Real  & 4 & 4 bytes & \texttt{DBD4} & DB1.DBD4 \\
\bottomrule
\end{tabular}
\end{center}

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 2 — Læse Bool, Int og Real fra DB1}]
\begin{minted}{python}
import snap7
from snap7.util import get_bool, get_int, get_real

# ====== PLC opsætning ==========
plc_ip      = "192.168.154.1"
rack        = 0
slot        = 1
port        = 1102
db_number   = 1
bool_offset = 0;  bool_size = 1
int_offset  = 2;  int_size  = 2
real_offset = 4;  real_size = 4

# ====== PLC forbindelse =========
client = snap7.client.Client()
client.connect(plc_ip, rack, slot, port)

# ====== Læs input ===============
raw_bool = client.db_read(db_number, bool_offset, bool_size)
raw_int  = client.db_read(db_number, int_offset, int_size)
raw_real = client.db_read(db_number, real_offset, real_size)

my_bool = get_bool(raw_bool, 0, 0)   # DB1.DBX0.0
my_int  = get_int(raw_int, 0)        # DB1.DBW2
my_real = get_real(raw_real, 0)      # DB1.DBD4

# ====== Logik ===================
print("Bool:", my_bool)
print("Int:", my_int)
print("Real:", round(my_real, 2))

# ====== Disconnect og destroy ===
client.disconnect()
client.destroy()
\end{minted}
\end{tcolorbox}

\section{Skrive data til PLC (db\_write)}
% ==============================================================================

For at \textbf{skrive} til PLC'en bruger vi \texttt{set\_bool}, \texttt{set\_int}
og \texttt{set\_real} til at modificere en byte-buffer, som derefter sendes med
\texttt{client.db\_write}.

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 3 — Skrive Bool, Int og Real til DB1}]
\begin{minted}{python}
import snap7
from snap7.util import get_bool, get_int, get_real

# ====== PLC opsætning ==========
plc_ip      = "192.168.154.120"
rack        = 0
slot        = 1
db_number   = 1
bool_offset = 0;  bool_size = 1
int_offset  = 2;  int_size  = 2
real_offset = 4;  real_size = 4

# ====== PLC forbindelse =========
client = snap7.client.Client()
client.connect(plc_ip, rack, slot)

# ====== Læs input ===============
raw_bool = client.db_read(db_number, bool_offset, bool_size)
raw_int  = client.db_read(db_number, int_offset, int_size)
raw_real = client.db_read(db_number, real_offset, real_size)

# ====== Logik ===================
set_bool(raw_bool, bool_offset, 0, False)
set_int(raw_int, 0, 20)
set_real(raw_real, 0, 111.2)

# ====== Skriv output ============
client.db_write(db_number, bool_offset, raw_bool)
client.db_write(db_number, int_offset, raw_int)
client.db_write(db_number, real_offset, raw_real)

print("Bool skrevet:", get_bool(client.db_read(db_number, 0, 1), 0, 0))
print("Int skrevet:", get_int(client.db_read(db_number, int_offset, int_size), 0))
print("Real skrevet:", round(get_real(client.db_read(db_number, real_offset, real_size), 0), 2))

# ====== Disconnect og destroy ===
client.disconnect()
client.destroy()
\end{minted}
\end{tcolorbox}

\section{Betingede handlinger (if-sætning)}
% ==============================================================================

I dette eksempel læser vi en Bool fra PLC'en og bruger dens tilstand til at
bestemme hvilken Int-værdi der skrives tilbage.

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 4 — If-sætning baseret på PLC-data}]
\begin{minted}{python}
import snap7
from snap7.util import get_bool, get_int, set_int

# ====== PLC opsætning ==========
PLC_IP      = "192.168.154.120"
RACK        = 0
SLOT        = 1
DB_NUMBER   = 1
BOOL_OFFSET = 0;  BOOL_SIZE = 1
INT_OFFSET  = 2;  INT_SIZE  = 2

# ====== PLC forbindelse =========
client = snap7.client.Client()
client.connect(PLC_IP, RACK, SLOT)

# ====== Læs input ===============
raw_bool = client.db_read(DB_NUMBER, BOOL_OFFSET, BOOL_SIZE)
raw_int  = client.db_read(DB_NUMBER, INT_OFFSET, INT_SIZE)
my_bool  = get_bool(raw_bool, 0, 0)
my_int   = get_int(raw_int, 0)

# ====== Logik ===================
if my_bool == False:
    set_int(raw_int, 0, 35)
else:
    set_int(raw_int, 0, 88)

# ====== Skriv output ============
client.db_write(DB_NUMBER, INT_OFFSET, raw_int)
my_int = get_int(client.db_read(DB_NUMBER, INT_OFFSET, INT_SIZE), 0)
print("my_int =", my_int)

# ====== Disconnect og destroy ===
client.disconnect()
client.destroy()
\end{minted}
\end{tcolorbox}

\section{Fejlhåndtering (try / except / finally)}
% ==============================================================================

I produktionskode er det vigtigt at håndtere forbindelsesfejl.
Python's \texttt{try/except/finally} sikrer at forbindelsen \emph{altid} lukkes,
selv hvis der opstår en fejl undervejs.

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 5 — Robust fejlhåndtering}]
\begin{minted}{python}
import snap7
from snap7.util import get_bool, get_int, get_real

# ====== PLC opsætning ==========
plc_ip      = "192.168.154.12"
rack        = 0
slot        = 1
db_number   = 1
bool_offset = 0;  bool_size = 1
int_offset  = 2;  int_size  = 2
real_offset = 4;  real_size = 4

try:
    # ====== PLC forbindelse =========
    client = snap7.client.Client()
    client.connect(plc_ip, rack, slot)

    # ====== Læs input ===============
    raw_bool = client.db_read(db_number, bool_offset, bool_size)
    raw_int  = client.db_read(db_number, int_offset, int_size)
    raw_real = client.db_read(db_number, real_offset, real_size)

    # ====== Logik ===================
    set_bool(raw_bool, bool_offset, 0, False)
    set_int(raw_int, 0, 20)
    set_real(raw_real, 0, 111.2)
    print("Alt gik godt!")

    # ====== Skriv output ============
    client.db_write(db_number, bool_offset, raw_bool)
    client.db_write(db_number, int_offset, raw_int)
    client.db_write(db_number, real_offset, raw_real)

except Exception as e:
    print(f"Fejl: Kunne ikke forbinde til PLC — {e}")

finally:
    # ====== Disconnect og destroy ===
    client.disconnect()
    client.destroy()
    print("Forbindelsen er lukket og klient-objekt er destrueret.")
\end{minted}
\end{tcolorbox}

\begin{tcolorbox}[infobox, title={\faInfoCircle\quad try / except / finally forklaret}]
\begin{description}[leftmargin=2cm, style=nextline]
  \item[\texttt{try}] Kode der \textit{kan} fejle køres her.
  \item[\texttt{except}] Køres \textit{kun} hvis der opstod en fejl i \texttt{try}-blokken.
  \item[\texttt{finally}] Køres \textbf{altid} — uanset om der var fejl eller ej.
    Bruges til oprydning (disconnect/destroy).
\end{description}
\end{tcolorbox}

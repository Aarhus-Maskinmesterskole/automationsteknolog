\section{Introduktion}
% ==============================================================================

I dag 04 laerte vi at laese data fra en Siemens PLC via Data Blocks.
I dag 05 udvider vi med \textbf{write commands} --- vi skriver vaerdier
tilbage til PLC'en og arbejder desuden med PLC'ens fysiske I/O-omraader
(\%I, \%Q, \%M) ved hjaelp af \texttt{read\_area} og \texttt{write\_area}.

\begin{tcolorbox}[infobox, title={\faInfoCircle\quad Laes foer du skriver}]
Naar du skriver til en Data Block, skal du \textbf{altid laese det aktuelle
bytearray foerst}. Ellers risikerer du at overskrive bits i samme byte,
der styrer andre variable.\\[4pt]
Eksempel: Bool DBX0.0 og DBX0.1 deler samme byte (byte 0). Laes hele byten,
aendr kun det oenskede bit, skriv byten tilbage.
\end{tcolorbox}

% ==============================================================================
\section{Skriv til Data Block (db\_write)}
% ==============================================================================

Med \texttt{set\_bool}, \texttt{set\_int}, \texttt{set\_real} modificerer
vi et bytearray lokalt og sender det derefter til PLC'en med \texttt{db\_write}.

\begin{center}
\begin{tabular}{lcccp{4.5cm}}
\toprule
\textbf{Datatype} & \textbf{Offset} & \textbf{Stroerrelse} & \textbf{Funktion} & \textbf{TIA Portal navn} \\
\midrule
Bool & 0 & 1 byte & \texttt{set\_bool} & DB1.DBX0.0 \\
Int  & 2 & 2 bytes & \texttt{set\_int}  & DB1.DBW2 \\
Real & 4 & 4 bytes & \texttt{set\_real} & DB1.DBD4 \\
\bottomrule
\end{tabular}
\end{center}

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 1 --- Skriv Bool, Int og Real til DB1}]
\begin{minted}{python}
import snap7
from snap7.util import get_bool, get_int, get_real

# ====== PLC opsaetning ==========
PLC_IP      = "192.168.0.1"
RACK        = 0
SLOT        = 1
DB_NUMBER   = 1
BOOL_OFFSET = 0;  BOOL_SIZE = 1
INT_OFFSET  = 2;  INT_SIZE  = 2
REAL_OFFSET = 4;  REAL_SIZE = 4

# ====== PLC forbindelse =========
client = snap7.client.Client()
client.connect(PLC_IP, RACK, SLOT)

# ====== Laes input ===============
raw_bool = client.db_read(DB_NUMBER, BOOL_OFFSET, BOOL_SIZE)
raw_int  = client.db_read(DB_NUMBER, INT_OFFSET, INT_SIZE)
raw_real = client.db_read(DB_NUMBER, REAL_OFFSET, REAL_SIZE)

# ====== Logik ===================
set_bool(raw_bool, 0, 0, True)   # saet DBX0.0 til True
set_int(raw_int, 0, 123)          # saet DBW2 til 123
set_real(raw_real, 0, 123.45)     # saet DBD4 til 123.45

# ====== Skriv output ============
client.db_write(DB_NUMBER, BOOL_OFFSET, raw_bool)
client.db_write(DB_NUMBER, INT_OFFSET, raw_int)
client.db_write(DB_NUMBER, REAL_OFFSET, raw_real)

print("Bool:", get_bool(client.db_read(DB_NUMBER, BOOL_OFFSET, BOOL_SIZE), 0, 0))
print("Int:", get_int(client.db_read(DB_NUMBER, INT_OFFSET, INT_SIZE), 0))
print("Real:", round(get_real(client.db_read(DB_NUMBER, REAL_OFFSET, REAL_SIZE), 0), 2))

# ====== Disconnect og destroy ===
client.disconnect()
client.destroy()
\end{minted}
\end{tcolorbox}

\section{Fysiske indgange og udgange (\%I, \%Q, \%M)}
% ==============================================================================

Ud over Data Blocks kan vi med \texttt{read\_area} og \texttt{write\_area}
tilgaa PLC'ens fysiske I/O-omraader direkte.

\begin{tcolorbox}[infobox, title={\faInfoCircle\quad Omraade-konstanter i snap7}]
\begin{tabular}{lll}
\textbf{Konstant} & \textbf{Omraade} & \textbf{Eksempel} \\
\texttt{S7AreaPE} & Fysiske indgange & \%I0.0 \\
\texttt{S7AreaPA} & Fysiske udgange  & \%Q0.0 \\
\texttt{S7AreaMK} & Memory bits      & \%M0.0 \\
\texttt{S7AreaDB} & Data Block       & DB1 \\
\end{tabular}
\end{tcolorbox}

\subsection{Laes fysisk indgang (\%I)}

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 2 --- Laes fysisk indgang \%I0.0}]

\section{Fejlhaandtering (try / except / finally)}
% ==============================================================================

Brug \texttt{try/except/finally} til at sikre at forbindelsen
\emph{altid} lukkes --- ogsaa hvis der opstaaar en fejl undervejs.
Med \texttt{client.get\_connected()} kan vi tjekke forbindelsen foer vi
kalder disconnect.

\begin{tcolorbox}[pythonbox, title={\faPython\quad Kode 5 --- Robust fejlhaandtering}]
\begin{minted}{python}
import snap7
from snap7.util import get_bool, set_bool
from snap7.type import Area

# ====== PLC opsaetning ==========
PLC_IP   = "192.168.0.1"
RACK     = 0
SLOT     = 1
AREA     = Area.PA
Q_OFFSET = 0;  Q_SIZE = 1

try:
    # ====== PLC forbindelse =========
    client = snap7.client.Client()
    client.connect(PLC_IP, RACK, SLOT)

    # ====== Laes input ===============
    q_bytes_raw = client.read_area(AREA, 0, Q_OFFSET, Q_SIZE)

    # ====== Logik ===================
    set_bool(q_bytes_raw, 0, 0, True)
    print("Alt gik godt!")

    # ====== Skriv output ============
    client.write_area(AREA, 0, Q_OFFSET, q_bytes_raw)

except snap7.exceptions.Snap7Exception as e:
    print(f"Snap7 fejl: {e}")
except Exception as e:
    print(f"Uventet fejl: {e}")

finally:
    # ====== Disconnect og destroy ===
    if client.get_connected():
        client.disconnect()
        print("Forbindelsen er lukket.")
    client.destroy()
    print("Ressourcer frigivet.")
\end{minted}
\end{tcolorbox}

\begin{tcolorbox}[infobox, title={\faInfoCircle\quad try / except / finally forklaret}]
\begin{description}[leftmargin=2.2cm, style=nextline]
  \item[\texttt{try}]     Kode der \textit{kan} fejle koeres her.
  \item[\texttt{except}]  Fanger specifikke fejl ---
    \texttt{Snap7Exception} for PLC-fejl, \texttt{Exception} som fallback.
  \item[\texttt{finally}] Koeres \textbf{altid} uanset fejl.
    \texttt{get\_connected()} bruges til at tjekke forbindelsen foer disconnect.
\end{description}
\end{tcolorbox}

\begin{enumerate}[leftmargin=1.5em, itemsep=6pt]
  \item Skriv en Bool, Int og Real til \texttt{DB1} og laes dem tilbage for at verificere.

  \item Skriv til den fysiske udgang \texttt{Q0.0} --- taend og slaek den.
  \item Laes og skriv en memory bit \texttt{M0.0}.
  \item Omskriv et af eksemplerne med \texttt{try/except/finally} og brug

        baseret paa knappens tilstand (if/else).
\end{enumerate}

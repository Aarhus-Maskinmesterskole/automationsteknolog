# Dag 05 – Python til PLC 🐍🤖

## Formål

- Lære at kommunikere med PLC fra Python
- Skrive data til Siemens S7 (snap7) og Allen-Bradley (EtherNet/IP) <-- optional

---

## Opgaver

**01-snap7**
- Arbejd med Siemens S7 PLC
- Etabler forbindelse med snap7
- Skriv BOOL, INT, REAL, WORD

**02-ethernet-ip (optional)**
- Arbejd med Allen-Bradley PLC
- Læs tags med pycomm3

---

## Kompetencer du får 💡

- Forstå PLC-kommunikation fra Python
- Etablere forbindelse til Siemens S7
- Skrive forskellige datatyper

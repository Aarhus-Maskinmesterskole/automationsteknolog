# 📊 README – Dag 08: Visualisering og analyse med Pandas

Velkommen til femte undervisningsdag i Teknologi og Projektudvikling. Dagens fokus er på at give dine målinger og datalogning værdi gennem visuel formidling og statistisk bearbejdning. Du lærer at bruge Python-værktøjerne Pandas og Matplotlib til at analysere, sammenligne og præsentere data på en overskuelig og professionel måde.

Du bygger videre på erfaringerne fra dag 2 (CSV-import og Pandas-basics) og dag 4 (seriel data fra ESP32), og arbejder nu med rensning, filtrering, glidende gennemsnit, annoteringer og visuel sammenstilling af måleserier. Målet er at opnå overblik, indsigt og kunne producere figurer der kan anvendes i dokumentation, tests og præsentationer.

Dagens undervisning arbejder både med simulerede og rigtige målinger, og der lægges vægt på datakvalitet, sammenhæng i datasæt og meningsfulde grafer. Du lærer at anvende `.rolling()` til glidende gennemsnit, håndtere flere sensorer i én DataFrame, vælge passende visualiseringsformer og gemme dine figurer i høj kvalitet.

---

## 🎯 Formål med dagen

* Anvende `.rolling()` i Pandas til at beregne glidende gennemsnit over målinger
* Strukturere og sammenligne målinger fra flere sensorer i samme datasæt
* Visualisere data med tydelige akser, labels, farver og forklarende elementer
* Annotere vigtige datapunkter (f.eks. maksimum, tærskelværdi) direkte i grafer
* Eksportere grafer i høj kvalitet til brug i dokumentation, rapport eller præsentation
* Udvikle kompetencer i analyse og formidling af måledata i et teknologisk kontekst

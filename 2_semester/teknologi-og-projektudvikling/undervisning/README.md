# 📚 Undervisning – Python & Automation (2. semester)

---

## 📆 LEKTIONSPLAN – Teknologi og Projektudvikling (5 ECTS)

**Uddannelse:** Automationsteknolog  
**Semester:** 2. semester  
**Varighed:** 12 undervisningsdage  
**ECTS:** 5

---

Denne mappe indeholder kursusforløbet for automationsteknologer med fokus på Python, data, hardware og PLC-integration. Hver dag har sit eget tema og praktiske øvelser.



## Oversigt over undervisningsdage og læringsmål

- [**Dag01 - Teknisk dokumentation og tests**](./Dag01%20-%20Teknisk%20dokumentation%20og%20tests/)  
  Introduktion til teknisk dokumentation, test og arbejdsgange.  
  *Læringsmål: Forstå dokumentationskrav, testmetoder og struktur i projekter.*
- [**Dag02 - Intro github python**](./Dag02%20-%20Intro%20github%20python/)  
  Kom i gang med Python og versionsstyring med GitHub.  
  *Læringsmål: Kunne skrive, køre og versionere simple Python-programmer.*
- [**Dag03 - Arbejde med dag02**](./Dag03%20-%20Arbejde%20med%20dag02/)  
  Øvelser og fordybelse i Python og GitHub fra dag 2.  
  *Læringsmål: Opnå rutine i grundlæggende Python og Git-arbejdsgange.*
- [**Dag04 - Python PLC kommunikation**](./Dag04%20-%20Python%20PLC%20kommunikation/)  
  Grundlæggende kommunikation mellem Python og PLC.  
  *Læringsmål: Forstå og afprøve dataudveksling mellem PC og PLC.*
- [**Dag05 - ESP32 intro**](./Dag05%20-%20ESP32%20intro/)  
  Introduktion til ESP32 og IoT-programmering.  
  *Læringsmål: Forstå grundprincipper i IoT og opsætte ESP32 til dataopsamling.*
- [**Dag06 Python pyserial**](./Dag06%20Python%20pyserial/)  
  Seriel kommunikation mellem Python og hardware.  
  *Læringsmål: Kunne sende/modtage data mellem PC og udstyr via seriel port.*
- [**Dag07 Python CSV Pandas intro**](./Dag07%20Python%20CSV%20Pandas%20intro/)  
  Datahåndtering og logning med CSV-filer og introduktion til Pandas.  
  *Læringsmål: Kunne logge og gemme data fra Python til fil.*
- [**Dag08 - Pandas visualisering**](./Dag08%20-%20Pandas%20visualisering/)  
  Databehandling og visualisering med Pandas og matplotlib.  
  *Læringsmål: Kunne analysere og visualisere måledata i Python.*
- [**Dag09 - Sanity timestamp**](./Dag09%20-%20Sanity%20timestamp/)  
  Tidsstempling, sanity checks og datakvalitet.  
  *Læringsmål: Forstå vigtigheden af datakvalitet og tidsstempling i automation.*
- [**Dag10 - Python databehandling**](./Dag10%20-%20Python%20databehandling/)  
  Avanceret databehandling og analyse i Python.  
  *Læringsmål: Kunne bearbejde og analysere større datasæt.*
- [**Dag11 - Realtime plotting**](./Dag11%20-%20Realtime%20plotting/)  
  Real-time dataopsamling og grafisk visning.  
  *Læringsmål: Kunne vise og opdatere måledata live i Python.*
- [**Dag12 - Opsummering evaluering**](./Dag12%20-%20Opsummering%20evaluering/)  
  Opsamling, evaluering og mini-projekt.  
  *Læringsmål: Samle viden i et mini-projekt og evaluere eget udbytte.*

## Sådan bruger du materialet

1. Start med dag01 og følg rækkefølgen.
2. Læs README og opgaver i hver dags mappe.
3. Løs øvelserne og eksperimentér med koden.
4. Spørg underviseren, hvis du sidder fast!

> Materialet er bygget op med fokus på praksis, automation og hands-on læring.

## 🧠 Metoder

* Praktiske øvelser og prototyper
* Opgaver i grupper (maks 3 personer)
* Brug af GitHub og Markdown som dokumentationsplatform
* Brug af Python som samlet analyse- og kommunikationsværktøj

## 📂 Ressourcer og værktøjer

* Python (VS Code eller Google Antigravity)
* ESP32 med sensorer (DHT22, potmeter, etc.)
* Siemens S7 PLC eller simulator (Snap7)
* Git + GitHub til versionsstyring og dokumentation

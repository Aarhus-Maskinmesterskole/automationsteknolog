# 📘 README – Dag 01: Teknisk dokumentation og tests

Denne mappe indeholder dag 1-materiale (PDF’er) til at komme i gang med teknisk dokumentation og test i et projekt.

## 🎯 Formål

- Forstå hvad en kravspecifikation er, og hvordan den bruges
- Få overblik over teknisk dokumentation (struktur, indhold, kvalitet)
- Få introduktion til test (testcases, acceptkriterier, sporbarhed)
- Se eksempler og skabeloner du kan genbruge i dit projekt

## 📚 Materialer i mappen

Læs typisk i denne rækkefølge:

1. **Kravspecifikation**
   - `Dag 1.2 - Kravspecifikation.pdf`
   - `Dag 1.8 - Kravspec. eksempel.pdf`

2. **Teknisk dokumentation**
   - `Dag 1.3 - Teknisk dokumentation.pdf`
   - `Dag 1.10 - Doku. skabelon.pdf`
   - `Dag 1.9 - Teknisk dok. skabelon.pdf`
   - `Dag 1.11 - Doku. eksempel.pdf`

3. **Tests**
   - `Dag 1.4 - Teknisk tests.pdf`

4. **Diagrammer (oversigt og design)**
   - `Dag 1.5 - FlowChart.pdf`
   - `Dag 1.6 - Block diagram (BD).pdf`
   - `Dag 1.7 - State Machine (STM).pdf`

## ✅ Output for dagen

- En enkel kravspecifikation til dit projekt
- En teknisk dokumentation (evt. baseret på skabelon)
- En lille testplan/testcases med klare acceptkriterier

> Tip: Gem jeres dokumenter i repo’et sammen med koden, så dokumentation og udvikling følges ad.

# 📘 README – Dag 02: Intro til GitHub og Python

Dag 2 består af to spor:

- **GitHub/versionsstyring**: hvordan du arbejder sikkert med commits, branches og merge
- **Python**: et praksisnært introforløb med fokus på at kunne skrive, køre og fejlfinde scripts

## 📚 Struktur

Følg mappen i denne rækkefølge:

1. `01-github/` – GitHub og workflow
2. `02-python/` – Python-grundforløb

## ✅ Forslag til rækkefølge

1. Start i `01-github/01-github-python-intro.md`
2. Arbejd dig videre gennem GitHub-filerne (01 → 08)
3. Fortsæt med `02-python/01-intro-til-python.md` og frem

## 🎯 Output for dagen

- Du kan klone et repository og lave commits
- Du kan arbejde med branches og merge til `main`
- Du kan skrive og køre simple Python-programmer og fejlfinde dem

> Målet er ikke at kunne “alt”, men at kunne arbejde i et repo og skrive Python uden at gå i stå på de klassiske begyndersnubletråde.

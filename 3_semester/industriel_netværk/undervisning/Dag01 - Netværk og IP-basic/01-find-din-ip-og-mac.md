# 01 - Find din IP- og MAC-adresse

## 📝 Formål

Formålet er at gøre dig fortrolig med, hvordan du finder og tolker IP- og MAC-adresser på dit eget udstyr.  
Dette er en essentiel grundkompetence for at kunne fejlfinde og konfigurere industrielle netværk.

## 🎯 Kompetencer

- Kan identificere IP- og MAC-adresser på forskellige platforme (Windows, Mac, Linux)
- Forstår forskellen på IP og MAC
- Kan reflektere over basal adressering i netværk

---

## Sådan gør du

1. **Windows:**  
   - Åbn Kommandoprompt og skriv:  
     ```
     ipconfig /all
     ```
2. **Mac/Linux:**  
   - Åbn Terminal og skriv:  
     ```
     ifconfig
     ```

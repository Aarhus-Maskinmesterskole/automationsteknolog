## 💡 Vigtige noter

- **IP-adresser:** Brug jeres egen IP-adresse - ikke dem fra videoguides
- **Profibus:** Husk terminering (ON) på første og sidste enhed
- **Test forbindelse:** Brug `ping` til at verificere netværksforbindelse
- **Dokumentation:** Tag screenshots af opsætning og resultater

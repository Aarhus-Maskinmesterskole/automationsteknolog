# Kepserver - Siemens S7 OPC-UA Server
> **Formål:** I denne øvelse skal du konfigurere en Siemens S7-1200 eller S7-1500 PLC som en OPC-UA server og bruge KepserverEX som OPC-UA client for at kommunikere med PLC'en.

## 🔌 Opgavebeskrivelse
1. Konfigurer din Siemens S7-1200 eller S7-1500 PLC som en OPC-UA server ved at følge videoen nedenfor.
2. Download og installer KepserverEX på din computer, hvis du ikke allerede har det.
3. Opret en ny kanal i KepserverEX og vælg OPC-UA som driver.
4. Konfigurer driveren med de korrekte indstillinger for din PLC (IP-adresse, port, etc.).
5. Opret en ny enhed i kanalen og tilføj de ønskede tags, som du vil læse/skrive til PLC'en.
6. Test kommunikationen ved at læse værdier fra PLC'en og skrive værdier til PLC'en via KepserverEX.

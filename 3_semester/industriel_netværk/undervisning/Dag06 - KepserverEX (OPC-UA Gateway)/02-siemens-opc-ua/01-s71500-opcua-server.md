# Siemens OPC-UA server
> **Formål:** I denne øvelse skal du konfigurere en Siemens S7-1200 eller S7-1500 PLC som en OPC-UA server og bruge en OPC-UA client (f.eks. KepserverEX) til at kommunikere med PLC'en.

## 🔌 Opgavebeskrivelse
1. Konfigurer din Siemens S7-1200 eller S7-1500 PLC som en OPC-UA server ved at følge videoen nedenfor.
2. Download og installer en OPC-UA client på din computer, hvis du ikke allerede har det (f.eks. KepserverEX).
3. Opret en ny kanal i din OPC-UA client og vælg den relevante driver for Siemens S7 PLC'er.
4. Konfigurer driveren med de korrekte indstillinger for din PLC (IP-adresse, port, etc.).
5. Opret en ny enhed i kanalen og tilføj de ønskede tags, som du vil læse/skrive til PLC'en.
6. Test kommunikationen ved at læse værdier fra PLC'en og skrive værdier til PLC'en via din OPC-UA client.

# HTTP requests i Node-RED og ESP32 Micropython
## Hvorfor HTTP?
HTTP er ikke blot en tilfældig valg for IoT og automation – det er *fundamentet* for moderne internetkommunikation. Her er hvorfor det betyder noget for dig:

**Universelt og enkelt**: HTTP kører på næsten enhver enhed med internetforbindelse. Fra din smartphone til PLCer på fabriksgulvet. Ingen proprietary protokoller eller specialiseret hardware – bare standard TCP/IP.

**Skalerbart**: En HTTP-server kan håndtere tusinder af klienter samtidigt. Skal du overvåge én ESP32 eller hundrede IoT-sensorer? HTTP skalerer ubesværet.

**Firewall-venligt**: De fleste netværk tillader HTTP-trafik (port 80/443). Mange alternative protokoller blokeres af virksomhedsfirewalls, men ikke HTTP.

**Integration med cloud**: AWS, Azure, Google Cloud, Firebase – de bygges alle omkring HTTP REST APIs. Når du lærer HTTP, åbner du døren til verdens største cloud-infrastrukturer.

**Industri 4.0-standard**: Moderne fabrikker og automatiseringssystemer (som AAMS-projekterne) forbinder sig via HTTP til IoT-platforme, MES-systemer og analytics-værktøjer. Det er det sprog, som industrien taler.

**Byggeklodser for komplette systemer**: Med HTTP kan du bygge alt – fra simpel sensorudlæsning til fulde webhooks, real-time dashboards og distribuerede systemer. En enkelt protokol, uendelige muligheder.
